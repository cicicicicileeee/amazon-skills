# cici-amazon-brand-research · v1.0.0

输入品牌名和亚马逊站点，研究品牌经营、产品类目、竞品、目标国家官网和消费者抱怨，并给出有来源的市场调研报告及数据。适合品牌经营诊断与增长机会分析。

## 使用

在支持Skill的助手中安装本文件夹后输入：

```text
使用 $cici-amazon-brand-research 调研 Anker 在 Amazon.de 的经营表现。
```

```text
使用 $cici-amazon-brand-research 调研一个家居品牌在 Amazon.com 的市场，优先分析消费者的耐用性与售后抱怨，报告输出为Word和Excel。
```

默认近12个完整月逐月研究，相关类目最近一个月Top100，2—3款重点产品，每款3—5款直接竞品。官网以目标国家为主；当地官网缺失时查美国或全球官网。社媒优先目标国家近12个月公开内容，Amazon低星评价独立统计。

只提供品牌与站点即可启动。可附加周期、品牌别名/子品牌范围、竞品、ASIN、已有数据、输出格式或深挖项。门店与全球官网遍历是可选项。

无需Skill安装的独立提示词见 [PROMPT.md](PROMPT.md)。可调用的正式流程见 [SKILL.md](SKILL.md)。

## 能力与依赖

- 优先使用当前可用的Sorftime MCP、公开网页/合规浏览器与用户授权数据。需要相应数据工具的访问权限；不内置密钥，也不读取钥匙串密码。
- 运行时发现工具支持的站点和字段，未覆盖部分明确列为数据缺口。工具缺失时不能保证取得销量或历史数据。
- 标准库脚本可初始化研究目录、校验输入、按计量键聚合月度数据、去重抱怨样本并汇总主题。它们不直接调用远程API，也不保证自动抓取所有网站。
- 输出格式按当次要求。未指定时至少生成Markdown报告、标准化数据及来源索引；Word/PDF/Excel需所在环境具备对应能力。
- 将完整文件夹放进当前助手的技能目录即可使用；必须保留references、scripts和assets，不能只复制SKILL.md。

本技能强调覆盖披露：第三方预估不等于后台实销，购买入口不等于有货，Top100不等于全市场，社媒负面样本不能推算总体投诉率。

## 每次运行后的优化建议

每次研究附一份独立优化提案，说明真实问题、证据、拟改动、收益与验证方法。你决定是否修改技能；默认不自动更新文件、配置或仓库。
